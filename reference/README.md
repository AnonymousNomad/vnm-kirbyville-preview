## What was used as the visual authority

The written doctrine in the build brief, reproduced here so this directory is
self-describing:

> Dark East Texas atmosphere + premium smoke-shop retail + restrained cyan/teal neon +
> warm product lighting + subtle atmospheric vapor.

Composition per the brief:

- Header: brand identity left, `Kirbyville · Texas` beneath, nav (Home, Products, About,
  Reviews, Location, Contact), dark-glass premium treatment.
- Hero: local eyebrow, "Kirbyville's Go-To / Vape & Smoke Shop", supporting copy, primary
  Call/Contact CTA, secondary Directions CTA, staged product composition on the right.
- Product categories: Disposables, E-Liquids, Glass & Accessories, Rolling Supplies, More.
- Local value: "Why Locals Choose Us".
- Reviews: framework only — no fabricated identities, quotes, or ratings.
- Location: Kirbyville-specific presentation with a directions CTA, no invented address.
- Footer: identity, navigation, 21+ notice, responsible-use language, preview attribution.

## Imagery note

No product photography exists for this store, so the hero uses an original, brand-free
SVG composition (abstract device / bottle / glass silhouettes under warm and cyan
lighting) — not a screenshot, not stock photography, and not a claim about brands
carried. It is captioned in the UI as an illustrative composition.
